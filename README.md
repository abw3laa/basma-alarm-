# منبّه بصمة — Android / Kotlin

تطبيق Android أصلي بلغة **Kotlin** وواجهات **Jetpack Compose**. معرّف الحزمة الثابت هو `com.abw3laa.basmaalarm`، والحد الأدنى Android 6.0 (API 23). التطبيق موجّه للتثبيت المباشر، وليس للنشر عبر Google Play.

## الوظائف

- واجهات رئيسية ومواعيد قادمة وسجل منفصل، وإعداد/تعديل/حذف جدول البصمات. الشاشة الرئيسية والمواعيد والسجل تبدأ فارغة حتى يحفظ المستخدم جدولاً؛ لا تُنشأ مواعيد تجريبية.
- دورة كل 28 يوماً أو أسبوعية، مع عدد دورات قابل للتعديل. التنبيهات مجدولة عبر `AlarmManager`، وتُعاد جدولة المنبهات المفقودة بعد الإقلاع من خلال مهمة نظامية مستمرة.
- نافذة تذكير لثلاثة أيام، وتذكير اختياري قبل الموعد بيوم وفي اليوم الثاني. يمكن تكرار تنبيه يوم الموعد حتى التوثيق.
- اختيار نغمة الجهاز أو الصمت، والاهتزاز، ووقت افتراضي، والإيقاف التلقائي، والغفوة، وأولوية التنبيه.
- خيار «ذكرني لاحقاً» يؤجل التنبيه فقط ولا يسجل اكتمال البصمة؛ حالة «مكتمل» في السجل تتطلب تأكيداً صريحاً، أما الموعد غير المؤكد فيظهر بوضوح «غير موثّق».
- واجهة تنبيه فوق التطبيقات عند منح الإذن، وشاشة تظهر فوق القفل، مع أزرار التأكيد والغفوة وكتم الصوت. توفر Android/OEM والأذونات تؤثر في ظهور التنبيه.
- إعدادات حقيقية للإشعارات والمنبهات الدقيقة والظهور فوق التطبيقات واستخدام البطارية وملء الشاشة.
- العربية والتركية والإنجليزية. اتجاه RTL للعربية وLTR للتركية والإنجليزية، مع ثيمين فاتح وداكن.
- يبدأ التثبيت الجديد بالوضع الداكن؛ تظل التفضيلات التي اختارها المستخدم محفوظة عند التحديث.
- معلومات التطبيق والمطور وروابط WhatsApp وTelegram وFacebook، وإخلاء المسؤولية المعتمد في التصميم.
- فحص التحديث عند فتح التطبيق. إذا كان هناك إصدار أحدث، يبدأ تنزيل APK في الخلفية ويظهر للمستخدم خيار التثبيت الآن أو التذكير لاحقاً. يتحقق التطبيق من بيان التحديث ورابط MediaFire ومضيف التنزيل وحجم APK ومعرّف الحزمة ورقم/اسم الإصدار وشهادة التوقيع قبل تمرير الملف إلى مثبت Android؛ وتُعاد محاولة خطأ الشبكة العابر مرة واحدة فقط. التثبيت النهائي يتطلب موافقة المستخدم وإذن التثبيت من هذا المصدر؛ لا يدعم Android التثبيت الصامت لهذا التطبيق.
- يحتفظ السجل بآخر 500 حدث فقط، ويمكن تصديره للمشاركة. تعطل حفظ حدث أو ملاحظة لا يُبلّغ عنه كنجاح؛ ويُحفظ إكمال الموعد وحدثه معاً في عملية كتابة واحدة.
- تعطيل Android Auto Backup ونقل بيانات التطبيق صراحةً لأن بيانات المواعيد شخصية.

## البناء بإجراءات GitHub

ملف `.github/workflows/android.yml` يجري اختبارات الوحدة وAndroid Lint وتجميع Debug في طلبات الدمج. بناء Release الموقّع مسموح فقط بعد نجاح التحقق وعلى فرع `main` أو تشغيل يدوي من `main`، ويستخدم بيئة GitHub المسماة `release`.

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

يستخدم workflow الأسماء أعلاه من سياق `secrets` داخل وظيفة Release. يمكنك إبقاء القيم الحالية كـ **Repository Actions secrets**؛ لا حاجة لنقلها أو تغييرها، وتستطيع GitHub أيضاً إتاحة أسرار بيئة `release` للوظيفة إذا استُخدمت. وظيفة Release مرتبطة ببيئة `release` المقيّدة إلى `main` فقط. لا تضع ملف keystore أو كلمات المرور في Git. يجب استخدام **ملف التوقيع نفسه** لكل إصدار لاحق، وإلا سيرفض Android التثبيت فوق النسخة السابقة. ينتج تشغيل Actions ملف Release ضمن artifact باسم `basma-release-signed`، ويفشل بوضوح إذا غاب أي سر مطلوب.

آخر إصدار عام هو `versionName=1.3.3` و`versionCode=7`. أُعدّ سابقاً مرشحا 1.3.4/8 و1.3.5/9 للاختبار، لكن الإصلاحات الجديدة لم تُنشر بعد. الفرع الحالي يجهّز مرشح `versionName=1.3.6` و`versionCode=10` متضمناً إصلاحات التدقيق. بيان `abw3laa/basma-alarm-updates` يبقى على الإصدار العام 1.3.3 إلى أن يُختبر المرشح ويُعتمد ويُرفع APK النهائي على MediaFire.

## التحديثات

يقرأ التطبيق البيان من:

`https://raw.githubusercontent.com/abw3laa/basma-alarm-updates/main/update.json`

يستخدم البيان `versionCode` و`versionName` و`apkUrl`. يمكن أن يكون `apkUrl` رابط صفحة مشاركة MediaFire الثابتة؛ يحاول التطبيق استخراج رابط الملف، ثم يستخدم خدمة Android `DownloadManager` للتنزيل في الخلفية. يعتمد نجاح ذلك على إمكانية الوصول إلى صفحة MediaFire من الجهاز. يجب ألا يشير البيان إلى رابط مؤقت من نوع `downloadNNN.mediafire.com` عند اعتماده كرابط طويل الأجل.

## مراجعة ما قبل الإطلاق

نجاح GitHub Actions يثبت الترجمة والتوقيع فقط، ولا يثبت سلوك الأجهزة. قبل التوزيع، اختبر النسخة **Release الموقّعة** على جهاز Android فعلي: ابدأ بلا جدول، أنشئ موعداً ثم عدّله واحذفه، بدّل اللغة والثيم، اختبر نغمة مخصصة، امنح الأذونات المطلوبة، اختبر الرنين والشاشة التراكبية بعد قفل الجهاز، وأجرِ تحديثاً فوق النسخة ذاتها. قيود البطارية وقنوات الإشعار وسياسات Android/OEM تختلف بين الأجهزة. لم يُجرَ اختبار جهاز فعلي في بيئة البناء هذه.
